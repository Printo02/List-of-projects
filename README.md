## Irrigation-Management-system ![Blue](https://img.shields.io/badge/Status-Completed-blue)

**Cost Analysis and Tendering of Irrigation Department** is a web-based application developed to automate the cost estimation and tendering process for construction projects handled by the Irrigation Department. The system allows officials to publish project details and estimated costs online, while registered contractors can submit tenders for available projects. Project notices are also made accessible to the public through an online notice board. The system reduces the time and effort involved in manual Excel-based cost estimation, improves data security, and provides a more efficient and organized tender management process.

## InstaMech ![Blue](https://img.shields.io/badge/Status-Completed-blue)

**InstaMech** is a roadside assistance platform developed as my BCA mini project, designed to help users quickly find and connect with nearby mechanics, crane services, and vehicle transportation services during emergencies. It provides a convenient way to request roadside assistance and receive timely support when a vehicle breaks down or requires emergency service.
